# Practice

Solved problems, kept separate from the learning notebooks in the numbered
folders at the repository root.

| Folder | Contents |
|--------|----------|
| [`hackerrank/`](hackerrank/) | Solutions to the HackerRank **Python** track, organised by its domains |
| [`problem_solving/`](problem_solving/) | Topic-wise DSA practice, grouped by technique rather than by platform |

## Conventions

- **One file per problem**, named after the problem in `snake_case`.
- Plain `.py` files, not notebooks — they diff cleanly and render well on GitHub.
- Every file opens with a short docstring: the problem, the approach, and the
  time/space complexity.
